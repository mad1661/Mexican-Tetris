MUSIC / LOOP SLOT
=================

Drop a looping background track here and the in-game "♪ MUSIC" button
will play it automatically (the <audio id="bgm"> element loops by default).

Expected filenames (add whichever you have):
  - music.mp3   (preferred)
  - music.ogg   (fallback)

The <audio> tag in index.html already points at these paths, so no code
changes are needed -- just add the file(s). A short seamless loop
(banda / cumbia / norteño would fit the theme) works great.
